# School Management System

## Sobre o Projeto

Este projeto foi desenvolvido durante as aulas de JavaScript da Kaizen Software Labs.

O objetivo é construir um Sistema de Gestão Escolar enquanto são aprendidos conceitos modernos de JavaScript, como modularização, objetos, classes, serviços e organização de projetos.

Este sistema ainda está em desenvolvimento e novas funcionalidades serão implementadas nas próximas Sprints.

---

## Funcionalidades Atuais

Atualmente o sistema possui:

- Cadastro de alunos;
- Cadastro de professores;
- Consulta de alunos;
- Registro de faltas;
- Estatísticas básicas;
- Arquitetura modular;
- Documentação técnica inicial.
