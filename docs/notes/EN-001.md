# Módulos e Dependências

## Objetivo

Este documento registra pequenas observações técnicas feitas durante o desenvolvimento do projeto.

Seu objetivo é ajudar a equipe a lembrar conceitos importantes utilizados nesta Sprint.

---

# Módulos

Durante esta Sprint aprendemos a dividir o sistema em vários arquivos.

Cada arquivo possui uma responsabilidade específica.

Essa organização facilita a leitura e a manutenção do projeto.

---

# Imports

Utilizamos **import** para utilizar funções, classes ou variáveis criadas em outros arquivos.

Exemplo:

```javascript
import { cadastrarAluno } from "./student-service.js";
```

---

# Exports

Utilizamos **export** para permitir que outros módulos utilizem nosso código.

Exemplo:

```javascript
export function cadastrarAluno() {

}
```

---

# Dependências

Alguns arquivos precisam utilizar recursos que estão em outros módulos.

Por isso, é necessário importar corretamente esses recursos.

---

# Caminhos Relativos

Nesta Sprint utilizamos dois caminhos principais.

**./**

Representa a pasta atual.

**../**

Representa a pasta anterior.

---

# O que aprendemos nesta Sprint?

Exemplo:

- organizar melhor os arquivos;
- utilizar import e export;
- corrigir caminhos incorretos;
- entender como os módulos se comunicam.
